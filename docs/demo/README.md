# docs/demo/ — Client Demo Plan

Purpose: a **sell-the-concept demo** for Unique Laser Clinics, built from what is already certain
(staff message M01 + verified website facts W01–W08) before Gate sign-offs. The demo shows the
clinic itself, on two phones, and collects the answers that unblock Gates 1/3.

This folder does not replace the gated process: it is an alignment artefact, not a signed
requirement. Anything shown is marked real vs simulated in `01-demo-scope.md`.

Reading order:

1. `01-demo-scope.md` — what the demo shows, priority from M01, real vs faked
2. `02-demo-ui-direction.md` — brand tokens extracted from the live site CSS + how we differ
3. `03-demo-screens-and-script.md` — screen map, wireframe notes, 5-minute walkthrough script
4. `04-demo-build-plan.md` — scaffold, data, build/run path, task list
